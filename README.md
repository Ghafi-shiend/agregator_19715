# Web Agregator Berita SMKN 1 Bawang

Project ini adalah aplikasi web berbasis Laravel untuk mengambil berita dari website SMKN 1 Bawang menggunakan RSS Feed.

## Fitur
- Sinkronisasi berita otomatis
- Menampilkan daftar berita
- Pencarian berita
- Hapus semua data
- Pagination

## Teknologi
- Laravel
- MySQL
- Bootstrap

## Cara Menjalankan

1. Install dependency
composer install

2. Copy file env
cp .env.example .env

3. Generate key
php artisan key:generate

4. Atur database di file .env

5. Jalankan migration
php artisan migrate

6. Jalankan server
php artisan serve
