# Web Agregator Berita SMKN 1 Bawang

Project ini adalah aplikasi web berbasis Laravel untuk mengambil dan menampilkan berita dari website SMKN 1 Bawang menggunakan RSS Feed.

## 🚀 Fitur
- Ambil berita otomatis dari website SMKN
- Tampilkan daftar berita
- Pencarian berita
- Hapus semua data
- Pagination

## 🛠️ Teknologi
- Laravel
- MySQL
- Bootstrap 5
